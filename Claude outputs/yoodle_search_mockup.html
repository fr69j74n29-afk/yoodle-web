The active filter stays visible as a chip (tap ✕ to clear). Pins that don't match fade out. A short results sheet turns "nothing here" into Post a job.

Why on the map

The header only has room for a cramped box on a 375 px phone. On the map, search reads as "filter what I'm looking at", and the radius stays visible.

Helpers first

Near Toronto there are about 20 helpers and 0 open jobs, so search opens on Find help. A jobs-only search would mostly come up empty.

Category mismatch

Jobs use 5 categories (assembly, yard, moving, errands, other). Helpers use 11 (Cleaning, Pet Care, Snow…). Search needs one shared list, or a mapping between the two.

No backend needed (v1)

Filters the jobs and helpers already loaded (titles, helper bios, categories), inside the current radius. It can reuse the unused mapFilterCat / listFilterCat functions.
